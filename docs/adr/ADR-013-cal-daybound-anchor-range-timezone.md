# ADR-013: CAL 日界、日柱基准、支持范围与默认时区

- **状态：** 已批准
- **日期：** 2026-11-05
- **关联：** D-03、D-04、D-12、D-13、CF-03/CF-04/CF-05/CF-07、CAL 2.1/5.3/6.1/6.2/6.3/8.4
- **决策人：** 项目所有者
- **生效版本：** `CAL-RULE-v0.2` / `CAL-v0.2`（ADR-016 冻结）

## 背景

CAL 2.1 已给出默认支持范围，CAL 5.3 列出三个“待校核”的日柱基准候选，CAL 6.1/6.3 分别要求默认日界与默认时区，但均未形成正式 ADR。实现与测试已按建议值工作；若不把这些选择写成决策记录，CAL 规则集无法冻结，纳甲、择吉、黄历的日柱与日界语义也缺少可审计依据。

## 决策

1. **默认日界：** `ZICHU`（子初，23:00 起算次日）。用户可在设置中切换 `ZIZHENG`（子正，00:00 起算次日）。所有输出必须携带 `day_bound`。
2. **有效日期：**
   ```text
   ZICHU  且 local_hour >= 23  → effective_date = local_date + 1 天
   其余情况                    → effective_date = local_date
   ```
   `effective_date` 用于日柱、时柱、旬空、纳甲日辰、择吉日柱与黄历日柱。
3. **日柱纪日：** 使用格里高利历 JDN 连续纪日，不使用逐年查表：
   ```text
   day_index = (effective_jdn + 49) mod 60
   ```
   以 **1900-01-31 = 甲辰日** 为锚点，并用 **2000-01-01 = 戊午日** 交叉校验。锚点与公式不一致时以测试失败处理，不得临时改锚点迁就样本。
4. **支持范围：** 闭区间 `1900-01-31` ～ `2100-12-31`（含端点）。越界返回 `CAL_OUT_OF_RANGE`；设置页必须展示该范围，不得静默截断或回退近似算法。
5. **默认时区：** 默认设置值为 `Asia/Shanghai`，但接口必须显式接收 IANA 时区，不得从系统时区或硬编码时区隐式取值。历史记录保留原 `timezone`，不自动转换后重算。
6. **农历日锚与绝对时刻：** 农历日期固定按中国标准时间 `+08:00` 的民用日匹配预计算月表；节气、年柱、月柱与日柱按用户传入时区解析后的绝对时刻计算。该差异必须在接口文档中保持显式，不得混用两种日锚。
7. **日界影响边界：** 日界只影响日柱、时柱、旬空与 `effective_date`；不影响年柱、月柱、节气月建。历史记录保留原 `day_bound`，切换设置不得静默重算历史。
8. **规则层级：** 日柱 JDN 连续纪日与两锚点校验记为 **CL2**；默认日界、默认时区与范围配置记为 **CL3**。不得表述为唯一传统流派。

## 影响

- **文档：** CAL 5.3 由“待校核候选”改为已选基准；CAL 6.1/6.3 补充“显式传参、历史保留”；决策登记册 D-03/D-04/D-12/D-13 关闭。
- **代码：** `crates/cal/src/engine.rs` 的 `MIN_DATE`/`MAX_DATE`、`DayBound`、`effective_jdn` 与 `(effective_jdn + 49) % 60` 保持现状；`crates/domain/src/version.rs` 默认 `CAL-v0.2` 由 ADR-016 同步。
- **数据/金标准：** `anchors.rs` 固定 1900-01-31 甲辰、2000-01-01 戊午；`day_bound.rs` 固定 22:59/23:00/23:59 的 `ZICHU` 切换；`baseline_2025_2026.rs` 覆盖两年逐日结果。
- **隐私/合规：** 无新增持久化字段；时区与日界属于非敏感配置，但必须随历史记录保存以支持复现。

## 验证

- `cargo test -p yitool-cal --test anchors`：1900-01-31 甲辰、2000-01-01 戊午、2026-11-03 锚点通过。
- `cargo test -p yitool-cal --test day_bound`：`ZICHU` 23:00 换日、`ZIZHENG` 00:00 换日通过。
- `cargo test -p yitool-cal --test timezone_dst`：显式时区、DST 重复/缺失按 ADR-006 处理。
- 越界日期返回 `CAL_OUT_OF_RANGE`；`yitool cal` 输出包含 `day_bound`、`effective_date`、`timezone`。
