# ADR-023: 含生辰复现提示与九色象意文案

- **状态：** 已批准
- **日期：** 2026-11-11
- **关联：** D-22、D-27、SRS O-04、O-05、IR v0.1、D-01/ADR-002
- **决策人：** 项目所有者
- **生效版本：** `APP-v0.2`（展示文案）/ `MEIHUA-INTERPRET-01`（仍为 `PENDING`）

## 背景

阶段 1 需要明确的“含生辰推演不可脱离原始输入长期复现”提示，以及九色象意文案的层级与合规边界。当前代码尚未开放生辰输入，但提示与文案必须先定，避免后续 UI 接入时产生“可长期复现”的误解或把 L3 自定义象意写成典籍结论。

## 决策

1. **含生辰复现提示（D-22）：** 任何含生辰的推演，结果页与报告固定显示：
   > 本次含生辰，仅本次会话有效；重算需重新输入，不承诺脱离原始输入长期复现。
   生辰不落盘、不入快照、不参与可长期复现种子；界面不得显示“可完全复现”或等价表述。
2. **九色象意文案（D-27）：** 九色象意属于系统自定义扩展（L3），文案必须：
   - 标注“本系统自定义，不是传统梅花易数原典标准”；
   - 不将颜色象意表述为吉凶定论；
   - 不进入纳甲起卦输入；
   - 与 `COLOR-NUM-02` 版本绑定，映射变更须升版且不重算历史。
3. **文案分级：** 象意文案优先级低于 ARS 计算结果与 IR 措辞等级；缺文案时显示“待校核/暂无文案”，不得用近似内容替代。
4. **报告同步：** 含生辰提示与九色 L3 声明同时出现在结果页、完整过程报告、复制文本与下载 `.md` 中；复制/下载不得移除。
5. **不改变规则状态：** 本决策只固定文案边界，不把 `MEIHUA-INTERPRET-01`、`IR-01` 或整体结果升为 `VERIFIED/FROZEN`；阶段 1 结果仍为 `PENDING`。

## 理由

- 生辰复现提示是隐私承诺的一部分，必须在输入入口与输出同时可见。
- 九色是 D-01 批准的 L3 输入；若不标注自定义属性，容易被误读为典籍原义。
- 文案不能反向影响算法或金标准，因此只固定展示与合规边界。

## 影响

- **代码：** 结果页/报告增加固定提示常量；九色选择器与结果区显示 L3 声明。
- **测试：** 断言报告、复制、下载均包含提示与 L3 声明；禁用词扫描仍通过。
- **文档：** 决策登记册关闭 D-22/D-27；IR 模板仍待冻结，文案不得作为正式解释。

## 验证

- 报告测试断言含生辰提示与九色 L3 声明。
- 前端测试断言结果页显示“本系统自定义”与“待校核”。
- `cargo test --workspace` 与前端测试通过。
