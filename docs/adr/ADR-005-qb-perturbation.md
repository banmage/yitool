# ADR-005: Q/B 扰动材料与启用语义

- **状态：** 已批准
- **日期：** 2026-11-04
- **关联：** A-04、D-07、ARS 3.1/3.2/3.3、SRS 3.3.5
- **决策人：** 项目所有者
- **生效版本：** `QB-v1`（`SEED` 扰动函数）/ `MEIHUA-QIGUA-001`、`MEIHUA-QIGUA-002`

## 背景

ARS 3.2 只给出 `Q_mod`/`B_mod` 的取值公式，未明确：

- 材料从哪里来、何时算“启用”；
- 材料缺失或格式错误时是否静默回退为 0；
- 问事历史关联（HMAC 入库）与 Q 扰动是否同一个开关；
- 传统数字模式启用 Q/B 后的公式；
- 扰动值越界时如何处理。

若不冻结，同一输入可能因调用方默认值不同而产生不同卦象，破坏复现与金标准。

## 决策

1. **默认关闭：** 用户未显式启用时 `Q_mod = 0`、`B_mod = 0`，公式退化为 ARS 3.2/3.3 默认形式。
2. **材料来源：**
   - `Q`：问事 HMAC（64 位十六进制）前 16 个字符，`int(...,16) mod 64`；
   - `B`：生辰材料（仅内存）SHA-256 摘要前 8 字节，`u64 mod 64`；
   - 两者均为 L3 自定义增强，必须标注“本系统自定义”。
3. **独立开关：** “保存问事 HMAC 用于历史关联”与“启用 Q 扰动”是两个独立开关。用户可以只关联不扰动，也可以只扰动不保存问事原文。
4. **不静默回退：** 显式启用但材料缺失、HMAC 非 64 位十六进制或摘要不可用时，返回错误；不得当作 0 继续计算。
5. **取值范围：** `Q_mod`、`B_mod ∈ 0..=63`。引擎必须拒绝越界值，不得用其他模数“修正”。
6. **不进入共同随机：** Q/B 只影响梅花起卦数字，不进入 `base_seed`/`draw_seed`/`snapshot_digest`/`run_seed`；A/B 统一对照仍按 ADR-004。
7. **传统数字模式：** 显式启用时采用
   ```text
   U = (U0 + Q_mod) mod 8; if U == 0: U = 8
   D = (D0 + B_mod) mod 8; if D == 0: D = 8
   M = (U0 + D0 + Q_mod + B_mod) mod 6; if M == 0: M = 6
   ```
   未启用时与 ARS 3.3 默认公式完全一致。
8. **隐私：** 生辰材料摘要与问事原文不得持久化、不得写日志；Q/B 结果只作为本次推演的步骤日志数值保留，不进入种子链或随机快照。

## 影响

- **文档：** ARS 3.2 增补材料与失败语义；ARS 3.3 增补传统数字扰动公式；决策登记册 D-07 关闭。
- **代码：** `crates/seed/src/perturbation.rs` 提供 `q_mod_from_question_hmac`、`b_mod_from_bazi`、`qb_mods`；`meihua::cast` 校验 `0..=63`；传统数字日志公式同步。
- **数据/金标准：** 默认金标准不变；新增越界、非法 HMAC 与范围测试。
- **隐私/合规：** 不新增持久化字段；问事原文仍不进入种子、快照或日志。

## 验证

- `cargo test -p yitool-seed perturbation`：`None→0`、前 16 位取值、非法输入拒绝、B 范围与确定性。
- `cargo test -p yitool-meihua q_b_perturbation_is_bounded`：`64` 被拒绝，`63` 可用。
- 默认参数下 `TC-MEIHUA-001`、`TC-MEIHUA-002` 结果不变。
