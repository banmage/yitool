# ADR-002: 九色唯一标准色集与映射

- **状态：** 已批准（2026-11-04 修订）
- **日期：** 2026-11-03（初版）/ 2026-11-04（修订）
- **关联：** O-01、F-01、D-01、D-21
- **决策人：** 项目所有者
- **生效版本：** COLOR-NUM-02 / RULE-v0.2

## 背景

SRS v0.4 与 ARS v0.2 推荐九色映射，但 O-01/F-01 要求产品冻结最终色集。初版 ADR 曾保留历史色制只读兼容；项目所有者于 2026-11-04 决定取消该兼容分支，系统只按九色设计。

## 决策

采用唯一九色标准：

| color_id | 名称 | 五行 | 象数 |
|---:|---|---:|---:|
| 1 | 赤色 | 火 | 1 |
| 2 | 橙色 | 土 | 2 |
| 3 | 黄色 | 土 | 3 |
| 4 | 绿色 | 木 | 4 |
| 5 | 青色 | 木 | 5 |
| 6 | 蓝色 | 水 | 6 |
| 7 | 紫色 | 金 | 7 |
| 8 | 黑色 | 水 | 8 |
| 9 | 白色 | 金 | 9 |

规则：

1. `COLOR-NUM-02` 是唯一颜色输入标准，`color_id ∈ 1..=9`。
2. 不保留其他色制的规则版本、只读数据、迁移分支、选择器或展示入口。
3. 灰色不进入标准色集，列为二期可选。
4. 映射变更须升 `COLOR-NUM-03`，历史记录不重算。
5. 九色不得用于纳甲起卦。

## 理由

- 单一色制减少输入、种子、金标准与 UI 分支，避免“九色/历史色制”双轨带来的版本与语义歧义。
- 阶段 0 尚未产生正式历史数据，直接切换成本最低。

## 影响

- **文档：** 删除历史色制只读兼容条款；SRS/ARS/数据字典/规格同步改为九色唯一输入。
- **代码：** 种子、梅花、存储与 CLI 只接受 1—9；不存在历史色制枚举或只读路径。
- **数据/金标准：** `resources/data/color_num.json` 仅保留 `nine_color` 九个条目；manifest checksum 更新。
- **隐私/合规：** 无变化。

## 验证

- `COLOR-NUM-02` 资源恰好 9 条，且不含任何其他色制字段或数据表 ID。
- `color_id=0` 与 `color_id=10` 均被拒绝。
- 九色抽卡卡方检验通过。
- 全仓库检索确认不存在历史色制资源、规则版本或 UI 入口。
