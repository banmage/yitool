# ADR-019: NJ-01 纳甲干支表校核与冻结

- **状态：** 已批准
- **日期：** 2026-11-05
- **关联：** F-04、D-46、ARS 1.7/附录 B、SRS 附录 A、ADR-018
- **决策人：** 项目所有者
- **生效版本：** `NJ-01-v0.2`（资源）/ `RULE-v0.2`（规则）

## 背景

`NJ-01` 纳甲干支表此前状态为 `PENDING`，资源只有八卦六爻干支展开，缺少表 ID 与校核来源，也没有对纳干、纳支规则做自动化对账。该表是纳甲六爻装卦、六亲与变卦计算的基础；在阶段 3 实现前先完成校核，可避免后续用实现输出反填数据。

## 决策

1. **完整表：** `NJ-01-v0.2` 固定八经卦 × 六爻共 48 个干支条目，按初爻至上爻排列。
2. **校核来源：** 以 ARS v0.2 附录 B 为基线，对照《京氏易传》纳甲与通行纳甲装卦歌：
   - 纳干：乾内甲外壬、坤内乙外癸、震庚、巽辛、坎戊、离己、艮丙、兑丁；
   - 纳支：阳卦（乾、震、坎、艮）顺行阳支，阴卦（坤、巽、离、兑）逆行阴支；
   - 起始地支：乾子、坤未、震子、巽丑、坎寅、离卯、艮辰、兑巳。
3. **金标准：** 新增 `tests/golden/nj01_najia.json`，保存八经卦、内外天干与 48 个干支条目。
4. **对账：** 测试校验金标准完整性、资源逐项一致、内外天干规则、阴阳顺逆地支规则与干支合法性。
5. **状态：** 资源 `NJ-01-v0.2` 记为 `VERIFIED`；`NJ-01` 作为数据表不再列为 `PENDING`。
6. **不升全局版本：** 数据基线仍为 `DATA-v0.2`，规则集仍为 `RULE-v0.2`；本次只校核数据表，不新增纳甲引擎规则。
7. **不代表纳甲引擎可发布：** `LIUYAO-YONGSHEN-01`、变卦六亲（D-09）与纳甲装卦实现仍未完成，纳甲引擎结果不得作为正式结论。
8. **历史兼容：** 历史记录按原版本渲染，不因本次校核静默重算。

## 影响

- **数据：** `resources/data/najia.json` 增加 `id`，版本升为 `NJ-01-v0.2`，状态升为 `VERIFIED`，来源写明纳甲规则；重新生成 manifest/checksum。
- **测试：** 新增 `crates/rules/tests/najia_crosscheck.rs`，覆盖 48 个干支条目与纳干/纳支规则。
- **文档：** SRS/ARS/数据字典/决策登记册/路线图/README/AGENTS/阶段 0 验收记录同步。
- **合规：** 无变化；本表只提供装卦基础数据，不生成吉凶结论。
