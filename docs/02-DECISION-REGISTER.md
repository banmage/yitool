## 6. 维护规则

1. 任何决策关闭前，必须先在对应文档中形成条款，再改代码。
2. 决策变更必须新增 ADR 或修订原 ADR，并保留历史。
3. 影响金标准的决策（D-01、D-04、D-09、D-11、D-30、D-33）必须同时更新金标准样例。
4. 每次阶段门评审时，核对本表状态；未关闭的阶段 0 项不得进入阶段 1。
